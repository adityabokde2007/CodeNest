================================================
   COPY AND RUN THESE COMMANDS IN ORDER
================================================

IMPORTANT: Open PowerShell or Terminal as Administrator

================================================
STEP 1: Install Google Cloud CLI
================================================

1. Download installer:
   https://cloud.google.com/sdk/docs/install#windows

2. Run the .exe file

3. Close and reopen PowerShell/Terminal

4. Verify installation:

gcloud --version

(Should show version number)

================================================
STEP 2: Authenticate
================================================

gcloud auth login

(Browser opens → Select your Google account → Allow)

================================================
STEP 3: Set Firebase Project
================================================

gcloud config set project codenest-63572

(Should show: Updated property [core/project])

================================================
STEP 4: Navigate to Project Folder
================================================

cd "C:\Users\ADMIN\OneDrive\Desktop\codenest"

(Or wherever your project is located)

================================================
STEP 5: Apply CORS Fix (THE IMPORTANT ONE!)
================================================

gsutil cors set cors.json gs://codenest-63572.firebasestorage.app

(Should show: Setting CORS on gs://...)

IF THAT FAILS, TRY THIS INSTEAD:

gsutil cors set cors.json gs://codenest-63572.appspot.com

================================================
STEP 6: Verify CORS Applied
================================================

gsutil cors get gs://codenest-63572.firebasestorage.app

(Should show JSON with your origins)

================================================
STEP 7: Test Upload
================================================

npm run dev

Then:
1. Open http://localhost:5173
2. Login
3. Go to Pictures tab
4. Click "Upload Image"
5. Select an image
6. Watch it upload successfully!

================================================
TROUBLESHOOTING:
================================================

"gsutil: command not found"
→ Restart terminal after installing gcloud
→ Try full path: "C:\Program Files (x86)\Google\Cloud SDK\google-cloud-sdk\bin\gsutil.cmd"

"AccessDeniedException: 403"
→ Run: gcloud auth login (again)
→ Make sure you use the Firebase project owner account

"BucketNotFoundException"  
→ Try: gsutil cors set cors.json gs://codenest-63572.appspot.com
→ Check Firebase Console > Storage for exact bucket name

Still getting CORS errors?
→ Clear browser cache (Ctrl+Shift+Delete > All time)
→ Hard refresh (Ctrl+F5)
→ Wait 2 minutes for changes to propagate
→ Try incognito mode
