================================================
TROUBLESHOOTING
================================================

"gsutil: command not found"
→ Restart terminal completely after installing gcloud CLI
→ Make sure PATH includes Google Cloud SDK

"AccessDeniedException: 403"
→ Run: gcloud auth login
→ Make sure you use the same Google account as Firebase project owner

"BucketNotFoundException"
→ Try both bucket names:
  • codenest-63572.firebasestorage.app
  • codenest-63572.appspot.com

Still getting CORS after applying?
→ Clear browser cache (Ctrl+Shift+Delete → All time)
→ Hard refresh (Ctrl+F5)
→ Wait 1-2 minutes
→ Try incognito mode
